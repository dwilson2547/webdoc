# webdoc

A multi-user markdown knowledge base for notes and documents, shared between people in a browser and
agents over an OAuth MCP server (web chats and local agents read and write the same store). Closed,
owner-controlled domain taxonomies; user-defined document templates; semantic search plus literal
`find`; an activity log; public and org contribution domains.

Status: **design only** — nothing built yet. Design and roadmap: [`docs/design.md`](docs/design.md).
